How to read this experiment & data coverage

Roles: Named defense uses direct API defender fields or opposing play participants. Named help requires a helper ID or an explicit help sentence. A help flag alone identifies neither the helper nor the player receiving help. A rotation-only helper is kept separate from primary defense.

Alterations: Counts only explicit “rotates over and alters his shot” wording. A contest, block or help flag is not automatically an altered shot. “Not recorded” means the required detail is absent; “No attempts” means an empty sample.

Shooter comparison: Actual FG% minus a baseline from the same shooters’ exact shot types in the selected games, excluding shots where this player is named as a defender or helper. Each shooter/type needs at least three other attempts. Only matched shots enter the calculation; matched and reference counts appear below the difference. This is an observed comparison, not a shot-quality model or points saved.

On/off: Uses exact shot-time lineups from games whose reconstruction reconciles. Both sides use the same validated games; coverage is per player’s games played. eFG% accounts for made threes; 3PA share measures shot mix. Help-marked share uses only shots with a recorded help flag or named help. Lower FG/eFG is favorable; changing shot mix or help frequency is not inherently better. Free throws, possessions and off-ball actions without recorded actors are outside this panel.

Samples: The minimum flags limited evidence; it does not provide statistical confidence. On/off needs that many attempts on both sides. Teammates, opponents, tactics and game situation can explain differences.
